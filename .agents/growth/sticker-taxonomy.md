# 贴纸数据模型：主题包 → 角色 → 状态

更新：2026-11-21｜状态：19 个主题包 / 114 个角色 / 125 个状态图

## 三层结构

```text
主题包 Pack
  └─ 角色 Character
       └─ 状态 Variant / State
```

- **主题包 / 系列**：浏览与筛选单位。例如「海洋伙伴」「打工人情绪」。
- **角色**：贴纸库的一张卡，也是桌面上的一张图。例如「企鹅布丁」。
- **状态**：同一个角色的不同姿势，例如默认、睡觉、趴边、被拖拽。状态不是独立贴纸，不单独入册、不单独放桌面。

规则：

1. 一个角色只属于一个主题包。
2. 一个角色有一个默认状态，作为贴纸库封面。
3. 一个角色可以有 1..N 个状态，每个状态有自己的静态/动态、动画、台词、配色。
4. 贴纸库一张卡 = 一个角色；多状态显示「N 状态」徽标。
5. 主题包卡片显示角色数与状态图总数。
6. 格式筛选按角色聚合：全部状态静态 = **纯静态**；至少一个状态动态 = **含动态**。
7. 搜索覆盖角色名、包名、标签、状态名、状态台词。

## 新增一个包 / 角色

1. 用户切好图后，放到 `design/new-cut/<系列名>/01..06.webp`。
2. 在 `scripts/import-new-cuts.py` 的 `NEW_PACKS` 增加映射；或手动把文件复制成 `src/assets/stickers/<pack-id>-<n>.webp`。
3. 在 `packs.ts` 增加包元数据（`id/title/short/tagline/coverStickerId/subject/style/mood/accent/glow/tags`）。
4. 在 `stickers.ts` 的 `NEW_PACK_CHARACTERS` 增加 6 个种子（`id/name/en/tags/phrase`）。
5. 主题包抽屉自动出现新卡片及角色、状态图数量。
6. 在 `effects.ts` 的 `EFFECT_BY_PACK` 给新包配一个粒子特效兜底。

## 给一个角色增加状态

给同一个 `characterId` 添加状态。飞行员企鹅沿用 `crayon-pets-4`，新图存为 `crayon-pets-4--<state>.webp`，在 `stickers.ts` 的 `POSE_SETS` 配台词和状态。

```ts
{
  id: "crayon-pets-4--sleep",
  characterId: "crayon-pets-4",
  state: "sleep",
  name: "飞行员企鹅",
  ...
}
```

- 贴纸库自动合并成一张卡，显示「N 状态」。
- 主题包卡片按角色和状态图分别计数。
- 格式筛选自动按「纯静态 / 含动态」聚合。
- 桌面宠物仍然只有一只；状态由行为切换（默认、睡觉、趴边、被拖拽），缺状态回退默认。
- 仓库的多状态角色卡打开状态预览，首页可切换预览状态。桌面实例存默认贴纸 ID，右键固定状态可额外存 `pose`。

- 已删除「动态贴纸」导航页；动态只是格式属性，不再单独占一个页面。
- 侧边栏：首页 / 我的贴纸 / 设置。
- 「我的贴纸」的主题包筛选入口打开抽屉。主题包可与当前搜索和其他筛选组合，全部主题包仅清除包筛选。旧的 `#packs` 入口会进入 `#library` 并打开抽屉。
- 格式筛选标签为「纯静态 / 含动态」，避免多状态角色在静态/动态之间产生歧义。

## 贴纸模式

- **悬浮**：默认，可直接拖动贴纸。拖拽期间合并 pointermove，通过 translate 移动贴纸，松手再保存坐标。
- **重力**：Matter.js，向下重力、碰撞、翻滚、拖拽撞飞；锁定贴纸是静态障碍。
- **太空**：无重力，拖拽产生惯性，持续漂浮碰撞；锁定贴纸是静态障碍。
- 非悬浮模式可设置：
  - `tumble`：是否翻滚；关闭后 `inertia=Infinity`，角度始终 0。
  - `physicsFps`：30 / 60 / 120，物理步进按该频率累积执行，视觉最多跟随显示器刷新率。
- 物理位置停稳、切模式、页面退出时回写，运动帧不写存储。
- 物理层不再使用窗口 Region；命中由 12ms 光标轮询切换 `WS_EX_TRANSPARENT`，所以高速移动不会撕裂边缘。

## 锁定 / 解锁

- 每张贴纸的 `passthrough` 语义就是「锁定」：不能移动，点击穿透。
- 锁定贴纸仍完整绘制，只是从 `usePetHitRects` 的命中矩形中排除（`data-pet-passthrough`）。
- 鼠标在锁定贴纸上停留 1.2 秒，会在它上方/下方显示「解锁」按钮；按钮本身是 interactive rect，移上去后窗口变可点。
- 主窗口「桌面上的贴纸」里也有单张锁定/解锁按钮，作为兜底。
- 全局锁定：所有贴纸临时锁定并穿透，关闭后恢复每张贴纸自己的锁定状态。

## 多状态触发

- `useStickerPose` 根据角色已提供的状态决定触发。拖动优先显示被拎起，点击按最近手势或闲置状态显示眨眼、爱心或惊醒。闲置 15 / 45 / 90 秒依次趴下、打瞌睡、睡觉。
- 工作、点心、奶茶、音乐可从桌面右键「切换状态」固定。释放临时姿势后恢复固定状态。
- 正方形素材用统一底线和近似角色中心定位，避免姿势变换改变盒子尺寸、碰撞面积或点击区域。纸质贴纸套图带灰阴影时按高 alpha 外轮廓切图，边缘保留原抗锯齿，深色底检查所有状态。
- 仓库将搜索、主题包、格式和「多状态」放在一行。「更多筛选」包含内容、画风、情绪，生效后可在主界面单独移除。卡片图面保留动态、状态数、桌面数量，悬浮或聚焦时在图面内显示快速状态和添加按钮，触屏直接显示操作。点击主图打开预览。
