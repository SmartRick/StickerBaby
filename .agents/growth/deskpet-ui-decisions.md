# 贴纸宝宝 UI/交互偏好（用户明确要求）

更新：2026-11-21｜状态：已验证

改首页/侧栏/桌宠交互前先读这里。

## 品牌

- 软件正式名：**贴纸宝宝**（英文 Sticker Baby）。所有用户可见处用这个名字：窗口、托盘、侧栏、状态、README、设置页底部。
- 图标：`design/sticker-baby-logo.png`；系统图标用 `pnpm tauri icon` 生成；侧栏左上角用 `src/assets/brand/sticker-baby.webp`。
- 字体：统一使用资源圆体（`DeskPetBody`），标题/正文同一套；旧站酷庆科黄油体因缺字已移除；详见 `brand-and-fonts.md`。

## 首页

- Hero banner：`src/assets/banners/blue-meadow.webp`；另外两张 lilac / mint 备用。
- 展示台背景：`src/assets/rooms/room-1..3.webp`，顶部图片按钮循环切换。
- **展台贴纸必须真正居中**。踩过的坑：`max-w-[60%]` 会把图片按父容器压成 174×290，父容器虽居中但图片在父容器里左对齐，看起来始终偏左；去掉百分比 max，用 `clamp(190px,36vh,310px)` 正方形后，CDP 实测图片中心与展台中心偏差 0px。
- 展台名称和状态切换在左上角，“在桌面 ×N”放右下角。
- 展台底部用「创建贴纸」进入独立页面，侧栏也有入口。「AI 生成」在创建页内提供提示词输入和提交交互。
- 展台不支持清除/收起，不要 X 按钮；只能从右侧贴纸库换一只。
- 首页底部保留约 12px 边距。
- 不要收藏功能、不要收藏筛选/收藏卡片/favorites 字段。
- 贴纸仓库：标题右侧“查看全部”；没有副标题、没有底部“管理全部贴纸”；滚动区左右留 6px，防止选中蓝环被裁；容器底部内边距尽量小。
- 左侧栏：宽度 224px；选中项右侧不要蓝点；高亮项不要阴影、不要白色描边；整体下边不要白色描边线；不要“今日小提示”卡片，不要版本行，不要桌面数量状态（数量在顶栏）；打招呼小猫居中可点。
- 打招呼：文字在左上角；点击后 Q 弹一下、换下一只招手图并换文案；6 张来自 `design/waving`。

## 顶栏状态

- 左上角保留“贴纸宝宝 · N 张在线”状态；点击文字打开“桌面上的贴纸”弹窗，弹窗内可逐张移除、可全部清空。
- 状态文字后面有一个小垃圾桶图标，点击一键清空桌面（无二次确认）。
- 设置页不重复显示在线状态；设置页标题下的副文本和 v0.1.0 药丸已去掉。

## 桌面贴纸

- **hover 不显示名字标签，也不要 hover 工具条**；右键菜单包含全部能力。
- 左键拖动位置。悬浮、重力和太空模式均支持按住右键拖动缩放，取位移更大的轴。
- 缩放：乘法手感（`scale * (1 + delta/360)`），最小 **20%**、最大 250%；百分比徽标和虚线框只在真正移动后显示，单右键不显示。
- 右键菜单包含**左右翻转**、锁定/解锁、换一只、移除。
- 主窗口侧栏「互动」可选桌面上的贴纸、预览动作和设置中键动作。桌面贴纸右键菜单也可设置，默认「抚摸」。
- 手势以原尺寸直接出现，配合贴纸动作后淡出。减少动效时只显示和淡出手势。
- 桌面贴纸底部的椭圆投影已移除。手势素材保留原图透明度，使用 `src/assets/gestures/` 的六张独立 WebP。
- **锁定**统一控制拖动、缩放和点击穿透，锁定后贴纸仍然可见。关闭全局锁定后恢复每张贴纸的单独锁定状态。
- 鼠标在锁定贴纸上停留 1.2 秒，上方/下方出现「解锁」按钮；主窗口「桌面上的贴纸」里也有兜底开关。
- 置顶关闭后回到桌面层（`set_always_on_bottom`），不再浮在应用窗口上方。
- 自动降低透明度保留；锁定贴纸仍然参与透明度。
- 三种贴纸模式：悬浮 / 重力 / 太空；非悬浮模式可调翻滚与物理帧率 30/60/120。
- 悬浮模式下贴纸保留轻微 float/sway/bob/wiggle/breathe 动画，默认开启；设置页「轻微晃动」可关闭。
- 桌面点击和首页展台点击都必须有 Q 弹（`animate-pet-bounce`）；Rive 贴纸同时触发专属 greet，但不能只剩 Rive 而丢掉 CSS Q 弹。
- 不要再使用窗口 Region 或 `SetWindowRgn`；命中测试用 12ms 光标轮询切换 `WS_EX_TRANSPARENT`，详见 `tauri-overlay-region.md`。

## 点击特效（已实现第一版）

- `src/lib/effects.ts` 按贴纸 id 配不同特效：鱼、爪印、叶子、胡萝卜、雪花、水滴、星星、爱心、樱桃、音符。
- 桌面宠物单击和首页展台单击都会 Q 弹 + 气泡 + 对应粒子；粒子用 `StickerBurst`。
- 桌面层现在是全屏透明窗口（不再 Region 裁切），粒子容器仍建议标记 `data-pet-visual`，以便命中测试/菜单热区兼容。
- 左侧打招呼图用固定 180×180 盒子 + `object-contain`，不要再直接给 img 写 height/width，否则会被父级挤压。
- 首页左右两块都加 `h-full`，展台和贴纸仓库高度对齐；否则展台偏短，点击气泡会顶到场景外被裁。
