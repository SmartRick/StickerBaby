# 产品方向：贴纸软件，不是养成宠物

更新：2026-11-20｜状态：用户已明确

## 定位

这是一个**桌面贴纸 / 贴图软件**，不是宠物养成游戏。
“贴纸宝宝”是贴纸角色，不是需要喂食、升级、照顾的虚拟宠物。

因此以下方向**明确不合适**：

- 食盆、喂食、饥饿、饱食度
- 经验、等级、体力、亲密度养成的重数值系统
- 宠物窝/宠物房作为“养宠场景”
- 为了养成而养成的时间等待、日常任务链

## 合适的方向

### 主题包
- 搞怪/沙雕：表情包、文字梗、发疯/摸鱼/无语/震惊，点击出漫画字、汗滴、速度线、抖动。
- 首饰/时尚：项链、耳环、戒指、宝石，点击出星光、金粉、镭射/烫金反光；可以给其他贴纸叠戴。
- 国风/传统色、手账/胶带、食物、植物、像素/Y2K、节日限定、字母/名字定制。
- 3 张房间图是**展示台/贴纸板背景**，不是宠物房。

### 贴纸本身的玩法
- 真实贴纸质感：白色刀模边、投影、倾斜、翘边/撕贴、重贴、叠贴、翻转。
- 贴纸拼贴板：在房间/纯色/手账背景上自由排版，加文字、胶带、相框，导出 PNG/分享。
- 自定义贴纸：导入图片 → 自动抠图 → 加白边 → 命名入册；这是贴纸软件的核心能力。
- 贴纸册/主题包收集：轻量收集，不做养成数值。
- 文字贴纸：用现有圆润字体做“摸鱼中/无语/收到/加油”等文字贴纸。
- 叠贴/给贴纸戴首饰：首饰包贴纸可以叠在动物贴纸上，形成组合。
- 桌面布置：多张贴纸分层、锁定、穿透、拼贴墙；点击/双击/长按有不同反馈。
- AI：真实生成贴纸、自动抠图、风格预设、贴纸合集拆图；当前“AI 生成”只是随机，后续可升级。
- 声音：轻量撕贴/贴纸音效，可静音。

### 点击特效按主题走
- 搞怪：！？、笑死、无语、汗滴、速度线、抖动/漫画爆炸。
- 首饰：星光、钻石闪、金粉、镭射扫光。
- 动物：鱼、爪印、叶子、胡萝卜、雪花、水滴（已实现第一版）。
- 植物/食物（作为贴纸主题，不是喂食）：花瓣、落叶、碎屑、蒸汽。
- 节日：彩带、烟花、雪花、灯笼。
- 触发：单击、双击、长按、悬停、拖动、撕贴、叠贴、闲置、整点/节日。

## 第一批建议

1. 贴纸质感编辑：白边、阴影、描边、色相/饱和度、镭射/闪粉。
2. 自定义导入 + 自动抠图 + 白边。
3. 搞怪包 + 首饰包，各配 3–5 个专属点击特效。
4. 叠贴 / 贴纸板 + 导出分享。
5. 轻量贴纸册与“今日贴纸”。
